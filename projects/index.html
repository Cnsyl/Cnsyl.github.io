Lobster Dashboard

把 7 寸小屏、树莓派、WM8960 Audio HAT 和 OpenClaw Agent 组合成一个会听、会说、会思考、会变表情的桌面 AI 终端。

FEATURE MATRIX

项目亮点

它不只是一个网页面板，而是一个围绕小屏硬件、语音链路和本地 Agent 设计的交互设备。

01

全屏 Kiosk

支持 Chromium Kiosk 全屏运行和 systemd 开机自启，适合作为桌面常驻终端。

02

本地 Agent

通过 OpenClaw CLI 接入对话能力，带 pending 状态、限流和单飞控制。

03

语音闭环

从麦克风录音、STT 识别、发送给 Agent，到 TTS 合成和扬声器播放。

04

情绪角色

Lobster Emoji 会根据对话内容切换开心、思考、工作、难过、酷等状态。

05

模型路由

提供 auto / fast / strong 模式，根据问题复杂度自动选择更快或更强的模型。

06

中文输入

支持 Fcitx5 输入法切换，并提供网页内置拼音候选作为 fallback。
